多Agent竞品分析系统

一个面向竞品调研场景的多级 Agent 协作系统，支持从行业主题输入到候选筛选、证据采集、竞品分析、审校和报告输出的完整链路。

Python LLM Agent Controller -> Manager -> Executor Markdown JSON
编写目的
  • 验证多 Agent 分工协作在真实调研流程中的可行性。
  • 让系统自动完成候选发现、重点筛选、公开信息采集和报告生成。
  • 保留证据、结构化结果和审校信息，提升报告可信度。
突出价值
  • 三层 Agent 架构清晰，便于解释任务拆分和协作边界。
  • 用 ProjectContext、EvidenceItem、AnalysisFinding 等结构打通数据流。
  • 支持 Markdown 报告和 JSON 结构化结果双格式交付。
  • 接入 severity、blocking、suggestion 审校字段，让弱证据影响最终建议。
2026.03 独立设计开发 数据决策

亚马逊运营日志智能决策系统

面向亚马逊运营团队的数据决策系统，整合店铺、Listing、订单、FBA 库存、广告报表和运营日志，辅助运营复盘和异常诊断。

Python FastAPI Pandas NumPy scikit-learn ECharts
编写目的
  • 把分散的运营数据整合成可复盘、可分析、可展示的数据服务。
  • 通过销量、CTR、CVR、ACOS 等指标判断运营动作效果。
  • 自动识别断货风险、高 ACOS 低转化、高花费无订单等问题。
突出价值
  • 不是单纯展示报表，而是生成 P0/P1/P2 优先级任务和优化建议。
  • 体现数据清洗、指标建模、后端接口和可视化交付的完整能力。
  • 驾驶舱支持单品复盘、动作时间线、库存预警和执行计划。
  • 业务场景明确，能说明如何用数据驱动运营决策。

2026.05 独立开发 业务工具

发货打包程序v1.4

面向仓储发货场景的桌面端工具，覆盖 Excel 需求导入、SKU 映射、扫码装箱、箱规重量录入、装箱单导出和 Windows 可执行程序交付。

Python Tkinter openpyxl PyInstaller Excel 自动化
编写目的
  • 把人工整理发货需求、扫描商品、记录箱号和生成装箱单的流程工具化。
  • 让仓储人员可以在一个 GUI 中完成需求导入、扫码装箱、箱规维护和结果导出。
  • 减少手工 Excel 操作造成的漏扫、超扫、箱号错乱和模板格式不一致问题。
突出价值
  • 支持多模板 Excel 字段兼容、日期格式处理、SKU 映射和需求去重。
  • 实现超扫校验、扫描数量回写、箱号分组、体积重/计费重计算和重新打包处理。
  • 导出符合业务模板的装箱单，并处理 Excel 文件占用时的备用文件命名。
  • 通过 PyInstaller 打包为 Windows 可执行程序，适合非技术人员直接使用。
